# Invoice asli

Folder ini berisi invoice asli yang dikumpulkan tim. Isinya **data pribadi** (nama, alamat, nomor rekening, nominal), jadi gambar dan labelnya **tidak masuk git**. Hanya README ini yang di-commit.

- Sumber bersama: folder Google Drive tim. Link-nya hanya dibagikan di dalam tim dan tidak ditulis di repo.
- Unduh isinya ke folder ini. Struktur dan format labelnya sama dengan data sintetis. Contoh label yang di-commit ada di `data/synthetic/examples/` (dibuat di Fase 2).
- Jangan menyalin gambar atau label dari folder ini ke `reports/`, notebook yang di-commit, atau issue/PR.
- Cara melabeli (Label Studio + konverter ke format kita) ditulis di sini pada Fase 2.
